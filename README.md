# voiceassistance
A Python-based AI voice assistant named Maha with a Tkinter GUI. It supports voice commands, web searches, application launching, music playback, date and time information, and mathematical calculations using speech recognition and text-to-speech.
# Maha - AI Voice Assistant 🎙️

Maha is a Python-based AI Voice Assistant that can understand voice commands and perform different tasks using Speech Recognition, Text-to-Speech, and a Tkinter graphical user interface.

## 🚀 Features

- 🎤 Voice command recognition
- 🔊 Text-to-Speech responses
- 🖥️ User-friendly Tkinter GUI
- 🌐 Open Google
- ▶️ Open YouTube
- 🔎 Search the web
- 📚 Search Wikipedia
- 📝 Open Notepad
- 🧮 Open Calculator
- 🎵 Play music on YouTube
- 🕐 Tell the current time
- 📅 Tell the current date
- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Percentage calculation
- 🔢 Square calculation
- √ Square root calculation
- ⚡ Power calculation
- 🔄 Remainder calculation

## 🛠️ Technologies Used

- Python
- Tkinter
- SpeechRecognition
- pyttsx3
- Wikipedia
- Regular Expressions (re)
- Web Browser
- Threading
